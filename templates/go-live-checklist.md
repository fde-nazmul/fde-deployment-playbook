# Go-live checklist

- [ ] Backups taken of every system the agent can write to
- [ ] Secrets in environment/secret manager, never in code or logs
- [ ] Least-privilege API keys and accounts
- [ ] Human approval path tested end-to-end
- [ ] Deterministic fallback tested with the model disabled
- [ ] Daily budget cap and alert configured
- [ ] Monitoring: job success rate, volume, cost, success metric
- [ ] Summary report delivered to the client's usual channel
- [ ] Rollback tested
- [ ] Runbook delivered and walked through with the owner
